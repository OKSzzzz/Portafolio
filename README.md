## 🚀 Mis proyectos

### 🏨 HotelApp — Sistema de reservas hoteleras

Aplicación de escritorio desarrollada como proyecto de DAM para la gestión de un hotel de cuatro estrellas en Madrid.

La aplicación cuenta con tres apartados principales:

- **Inicio:** panel con un resumen de las 30 habitaciones, indicando cuántas están disponibles, ocupadas o en mantenimiento.
- **Habitaciones:** listado de habitaciones con tarjetas informativas y filtros por estado.
- **Reservar:** apartado destinado a la gestión de reservas.

**Características principales:**
- Interfaz gráfica desarrollada con JavaFX y FXML.
- Estilos personalizados mediante CSS.
- Carga de los datos del hotel, habitaciones y reservas desde archivos XML.
- Tarjetas reutilizables con información sobre tipo de habitación, precio, planta, capacidad, vistas y accesibilidad.
